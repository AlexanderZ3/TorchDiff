## 典型输入 Shape 约定

| 符号 | 含义 | 值（480p 81f，B=1） |
|---|---|---|
| B | batch size | 1 |
| T | 时间帧数（VAE时序压缩后） | 21（81帧÷4+1） |
| H | 空间高（VAE+patch后） | 30（480÷8÷2） |
| W | 空间宽（VAE+patch后） | 52（832÷8÷2） |
| N = T×H×W | 视频 token 总数 | 32760 |
| Nh | 注意力头数 | 12 |
| D | head_dim | 128 |
| P | sparse_ratio | 2 |
| P² | 2D skiparse 批扩倍数 | 4 |
| Ns | skiparse 后每份 seq_len | 8190（N/P²） |
| C_text | T5 输出维度 | 4096 |
| Lt | text token 数 | 512 |

## 一、PyTorch 函数层算子流（前向）

### 1.1 模型整体前向（OSPNextModel.forward）

```
输入
  x     : [B, 16, T_raw, H_raw, W_raw]  = [1, 16, 21, 60, 104]  (VAE latent)
  t     : [B]                            = [1]                    (flow-matching 时间步)
  text  : [B, 512, 4096]                = [1, 512, 4096]         (T5 文本特征)

─────────────────────────── Step 1: 视频 patch 嵌入 ──────────────────────────
Conv3d(in=16, out=1536, kernel=(1,2,2), stride=(1,2,2))
  输入  [1, 16, 21, 60, 104]
  输出  [1, 1536, 21, 30, 52]     ← 空间下采样×2，时间不变

patchify: rearrange "b c f h w → b (f h w) c"
  输出  [1, 32760, 1536]           ← 21×30×52=32760 tokens

─────────────────────────── Step 2: 时间步嵌入 ──────────────────────────────
sinusoidal_embedding_1d(freq_dim=256, t)
  输入  [1]
  输出  [1, 256]

time_embedding: Linear(256→1536) → SiLU → Linear(1536→1536)
  输出  [1, 1536]

time_projection: SiLU → Linear(1536→9216)
  输出  [1, 9216]  → unflatten(1, (6,1536)) → [1, 6, 1536]   ← e0，用于每层 AdaLN 调制

─────────────────────────── Step 3: 文本嵌入 ────────────────────────────────
text_embedding: Linear(4096→1536) → GELU(tanh) → Linear(1536→1536)
  输入  [1, 512, 4096]
  输出  [1, 512, 1536]

─────────────────────────── Step 4: Context Parallel 预切分 ─────────────────
（单机单卡跳过，多卡时按 cp_size 在 seq 维度切分 x）

─────────────────────────── Step 5: 30层 OSPNextAttentionBlock ──────────────
见 §1.2（Full Block）和 §1.3（Skiparse Block）

─────────────────────────── Step 6: Head 输出投影 ───────────────────────────
Head.forward(x [1,32760,1536], e [1,1536]):
  modulation [1,2,1536] + e.unsqueeze(1) [1,1,1536] → chunk(2) → e[0],e[1] 各 [1,1,1536]
  LayerNorm(x) → * (1+e[1]) + e[0]   [1, 32760, 1536]
  Linear(1536 → 1×2×2×16=64)
  输出  [1, 32760, 64]

─────────────────────────── Step 7: unpatchify ──────────────────────────────
rearrange "b (f h w) (x y z c) → b c (f x) (h y) (w z)"
  f=21,h=30,w=52, x=1,y=2,z=2,c=16
  输出  [1, 16, 21, 60, 104]    ← 与 VAE latent 同 shape，即预测的速度场 v
```

### 1.2 Full Block 前向（OSPNextAttentionBlock，skiparse_block_type=Full）

```
输入 x : [B, N, 1536]  = [1, 32760, 1536]
     e : [B, 6, 1536]
  text : [B, 512, 1536]

─── AdaLN 调制参数准备 ─────────────────────────────────────────────────────
modulation [1,6,1536] + e [1,6,1536] → chunk(6, dim=1)
  → e0..e5，各 [1, 1, 1536]      ← scale/shift/gate for self-attn、cross-attn、FFN

─── Self-Attention ──────────────────────────────────────────────────────────
y = LayerNorm(x) * (1 + e[1]) + e[0]          [1, 32760, 1536]

q = RMSNorm(Linear_q(y))                       [1, 32760, 1536]
k = RMSNorm(Linear_k(y))                       [1, 32760, 1536]
v =         Linear_v(y)                        [1, 32760, 1536]

view → [B, N, Nh, D]                           [1, 32760, 12, 128]

（若有 register tokens，先 split 出 [B, Nr, 12, 128]，追加回 q/k/v 首部）

RoPE: apply_rope(q, grid_sizes=(21,30,52))
  reshape x → [B, N, Nh, D//2, 2]
  cos/sin 乘法（实数域）
  stack+flatten → [B, N, Nh, D]                [1, 32760, 12, 128]
  同样对 k 做 RoPE

attention_with_mask → flash_attn_no_pad
  q,k,v: [B, N, 12, 128]
  输出  [B, N, 12, 128]                         [1, 32760, 12, 128]

flatten(2): [B, N, 1536]                        [1, 32760, 1536]
Linear_o: [B, N, 1536]

x = x + Linear_o_out * e[2]                    [1, 32760, 1536]

─── Cross-Attention（text→image） ───────────────────────────────────────────
q = RMSNorm(Linear_q(LayerNorm(x)))             [1, 32760, 12, 128]
k = RMSNorm(Linear_k(text))                     [1, 512,   12, 128]
v =         Linear_v(text)                      [1, 512,   12, 128]

flash_attn_no_pad（cross-attn 路径）             [1, 32760, 12, 128]
flatten + Linear_o                              [1, 32760, 1536]

x = x + cross_attn_out * e[3]

─── FFN ─────────────────────────────────────────────────────────────────────
y = LayerNorm(x) * (1 + e[4]) + e[3]           [1, 32760, 1536]
Linear(1536→8960) → GELU(tanh)                 [1, 32760, 8960]
Linear(8960→1536)                               [1, 32760, 1536]

x = x + ffn_out * e[5]                         [1, 32760, 1536]

输出 x : [1, 32760, 1536]
```

### 1.3 Skiparse Block 前向（2D，sparse_ratio=2）

Skiparse 相邻两层成对出现：**Single block** + **Group block**。

```
全局 x 在进入 skiparse block 之前的 shape: [B, 32760, 1536]

╔══════════════════════════════════════════════════════════╗
║  Single Block（偶数层，is_full2skiparse_block=True 时）  ║
╚══════════════════════════════════════════════════════════╝

rearrange_input: skiparse_2d_single
  'b (t h p w q) c -> (p q b) (t h w) c'
  T=21, H=30→h=15, W=52→w=26, p=q=2
  [1, 32760, 1536] → [4, 8190, 1536]
  语义：把 2D 空间上每隔 2 采样一次的 token 归为一个子批次

  text: Repeat (context_rearrange_input)
  [1, 512, 1536] → repeat(p=P²=4) → [4, 512, 1536]
  e: 同样 Repeat → [4, 6, 1536]

block_forward(x=[4, 8190, 1536], text=[4, 512, 1536])
  （内部流程与 Full Block 完全一样，只是 N 从 32760 缩小为 8190）
  Self-Attn: q/k/v [4, 8190, 12, 128] → flash_attn → [4, 8190, 12, 128]
  Cross-Attn: q [4, 8190, 12, 128], k/v [4, 512, 12, 128]
  FFN: [4, 8190, 8960]

rearrange_output: Identity（非边界 single block 输出不 reverse）
  输出保持 [4, 8190, 1536]

╔══════════════════════════════════════════════════════════╗
║  Group Block（奇数层）                                   ║
╚══════════════════════════════════════════════════════════╝

rearrange_input: skiparse_2d_single_to_group
  '(p2 q2 b) (txh_p1 p1 w_q1 q1) c -> (p1 q1 b) (txh_p1 p2 w_q1 q2) c'
  p1=q1=p2=q2=2，w_q1=W//4=13
  [4, 8190, 1536] → [4, 8190, 1536]（形状不变，但 token 重排）
  语义：把单块采样（间隔）模式换为组块采样（局部 2×2）模式

block_forward 同上

rearrange_output:
  若 is_skiparse2full_block=True（最后一个 sparse block）:
    skiparse_2d_group_reverse: [4, 8190, 1536] → [1, 32760, 1536]
    register_rearrange_output: Reduce → [1, Nr, 1536]（平均 P² 份）
  否则: Identity（保持 [4, 8190, 1536]，继续下一个 sparse pair）

最终 x 在回到 Full Block 前已还原: [1, 32760, 1536]
```

## 二、算子对应表（PyTorch 函数 → 底层算子）

### 2.1 矩阵运算类

| PyTorch 操作 | 底层算子 | NPU 算子名（CANN） | GPU 算子名（CUDA） |
|---|---|---|---|
| `nn.Linear(in, out)(x)` | GEMM / MatMul | `MatMul` / `BatchMatMul` | `cublasSgemm` |
| `nn.Conv3d(kernel, stride)(x)` | 3D 卷积 | `Conv3D` | `cudnnConvolutionForward` |
| `q @ k.T`（attention 内） | BatchedMatMul | `BatchMatMul` | `cublasGemmBatched` |
| `attn_score @ v` | BatchedMatMul | `BatchMatMul` | `cublasGemmBatched` |

### 2.2 Norm 类

| PyTorch 操作 | 底层算子 | NPU | GPU |
|---|---|---|---|
| `WanLayerNorm` (nn.LayerNorm) | LayerNorm | `LayerNorm` | `cudnnBatchNormalizationForward` |
| `WanRMSNorm` | RMSNorm | `RmsNorm` | 自定义 CUDA kernel |
| `x.pow(2).mean(-1)` in RMSNorm | Reduce | `ReduceMean` | `cub::DeviceReduce` |

### 2.3 激活与逐元素

| PyTorch 操作 | 底层算子 | NPU | GPU |
|---|---|---|---|
| `F.gelu(approximate='tanh')` | GELU-tanh | `Gelu` | `cudnnActivationForward` |
| `F.silu(x)` | SiLU/Swish | `SiLU` | 自定义 CUDA kernel |
| `x * scale + shift` | Mul + Add | `Mul`, `Add` | 逐元素 CUDA kernel |
| `x.chunk(6, dim=1)` | Split | `Split` | cudaMemcpy 视情况 |
| `torch.cat([...], dim=1)` | Concat | `Concat` | `cudaMemcpy` |
| `x.split_with_sizes(...)` | Split | `SplitD` | `cudaMemcpy` |

### 2.4 RoPE 相关

| PyTorch 操作 | 底层算子 | 说明 |
|---|---|---|
| `x.reshape(..., 2)` | Reshape | view，零拷贝 |
| `freqs.cos()` / `freqs.sin()` | Cos / Sin | 三角函数 kernel |
| `x1 * cos - x2 * sin` | Mul + Sub | 复数乘实数等价 |
| `torch.stack([o1,o2],-1).flatten(3)` | Stack + Reshape | 交织回原 layout |
| NPU 原版复数 RoPE | `view_as_complex` + 复数乘 | NPU 不支持，已替换为实数实现 |

### 2.5 Skiparse Rearrange

| 操作 | 底层 | 说明 |
|---|---|---|
| `rearrange(x, 'b (t h p w q) c -> (p q b) (t h w) c')` | Reshape + Permute | einops 展开为 transpose+reshape |
| `repeat(x, 'b n c -> (p b) n c')` | `expand` + `contiguous` / `repeat` | text/register 复制 |
| `reduce(x, '(p b) n c -> b n c', 'mean')` | ReduceMean over batch dim | register 输出时取平均 |
| `dist.all_to_all_single(...)` | AllToAll 通信 | 多卡 parallel skiparse |

### 2.6 FlashAttention（GPU/CPU fallback）

| 场景 | 调用路径 | 说明 |
|---|---|---|
| GPU + FA2 | `flash_attn_varlen_func` / `flash_attn_varlen_qkvpacked_func` | 变长序列，unpad 后调用 |
| GPU + FA3 | `flash_attn_interface.flash_attn_varlen_func` | 同上，H100 专用 |
| NPU | `flash_attn_no_pad` → `scaled_dot_product_attention` | FA 不可用时退回 SDPA |
| NPU with mask | unpad_input + varlen flash_attn | 有 padding mask 时先去填充 |

## 三、Skiparse Attention 内部算子流（核心）

以 **2D Single Block**（sparse_ratio P=2，N=32760，B=1）为例，完整追踪每一个算子。

### 3.1 进入 Block 前：Token 重排

```
全局 x: [1, 32760, 1536]   layout: (B, T*H*W, C)
视频 token 的空间排布: T=21 帧，H=30，W=52

skiparse_2d_single(x, grid_sizes=(21,30,52), sparse_ratio=2):
  目标：把 2D 空间上间隔 P=2 采样的 token 归入同一个子批次

  einops rearrange: 'b (t h p w q) c -> (p q b) (t h w) c'
  展开过程（实际算子）：
    ① Reshape: [1, 32760, 1536]
              → [1, 21, 15, 2, 26, 2, 1536]
              (t=21, h=H//P=15, p=2, w=W//P=26, q=2)
    ② Permute: [1, 21, 15, 2, 26, 2, 1536]
              → [2, 2, 1, 21, 15, 26, 1536]
              (维度顺序: p,q,b,t,h,w,c)
    ③ contiguous() → 触发实际内存拷贝（stride 不连续时）
    ④ Reshape: [2, 2, 1, 21, 15, 26, 1536]
              → [4, 8190, 1536]
              (P²*B=4, T*h*w=21*15*26=8190, C)

  输出: [4, 8190, 1536]

同时对 text 做 Repeat:
  einops_repeat: 'b n c -> (p b) n c', p=4
    ① expand [1,512,1536] → [4,512,1536]
    ② contiguous()
  输出: [4, 512, 1536]
```

### 3.2 Block 内 Self-Attention（含 RoPE）

```
输入 x: [4, 8190, 1536]

─── QKV 投影 ────────────────────────────────────────────────────────────────
Linear_q: MatMul [4, 8190, 1536] × [1536, 1536]ᵀ → [4, 8190, 1536]
RMSNorm_q:
  pow(2): [4, 8190, 1536]
  mean(dim=-1, keepdim=True): ReduceMean → [4, 8190, 1]
  rsqrt: [4, 8190, 1]
  x * rsqrt * weight: Mul×2 → [4, 8190, 1536]
view → [4, 8190, 12, 128]

同样: k [4, 8190, 12, 128]，v [4, 8190, 12, 128]（v 无 Norm）

─── RoPE 应用 ────────────────────────────────────────────────────────────────
apply_rope(q, grid_sizes=(21,30,52), skiparse_rerrange=rearrange_rope):

  Step A: freqs 准备（带 skiparse rearrange 的 cos/sin）
    rope_params 生成基础频率表 [1024, 64]（head_dim=128，分成三段：时、高、宽）
    cat 三段频率 → [1, 32760, 128]      (原始空间 32760 个位置的频率)
    rearrange_rope（skiparse_2d_single）：
      [1, 32760, 128] → [4, 8190, 128]  (与 x 的 skiparse 对齐)
    cos([4, 8190, 128]).unsqueeze(2) → [4, 8190, 1, 64]
    sin([4, 8190, 128]).unsqueeze(2) → [4, 8190, 1, 64]

  Step B: 应用 RoPE（实数域复数乘法等价）
    x_in = q.reshape(4, 8190, 12, 64, 2)  ← Reshape
    x1 = x_in[..., 0]   [4, 8190, 12, 64]  ← 实部
    x2 = x_in[..., 1]   [4, 8190, 12, 64]  ← 虚部
    cos_f repeat_interleave(12, dim=0) 对齐 → 不需要（freqs_B=4=B）
    o1 = x1 * cos_f - x2 * sin_f          ← Mul + Sub
    o2 = x1 * sin_f + x2 * cos_f          ← Mul + Add
    stack([o1,o2], dim=-1) → [4, 8190, 12, 64, 2]
    flatten(3) → [4, 8190, 12, 128]       ← Reshape
    （k 同样处理）

─── Attention 计算（对接 FlashAttention） ───────────────────────────────────
q: [4, 8190, 12, 128]
k: [4, 8190, 12, 128]
v: [4, 8190, 12, 128]
attn_mask: [4, 8190] (bool，处理 skiparse padding 的 valid mask)

attention_with_mask → flash_attn_no_pad(q, k, v, attn_mask, ...):

  【GPU 路径，有 mask，self-attn】:
    ① Stack QKV: torch.cat([q,k,v], dim=2)
                 → qkv [4, 8190, 36, 128]
    ② rearrange "b s three_h d -> b s (three_h d)"
                 → [4, 8190, 4608]
    ③ unpad_input(qkv, attn_mask):
         找出 mask=True 的位置，打包
         → x_unpad [nnz, 4608]，cu_seqlens [5]（batch_size+1=5个偏移）
    ④ rearrange "nnz (three h d) -> nnz three h d"
         → x_unpad [nnz, 3, 12, 128]
    ⑤ flash_attn_varlen_qkvpacked_func(
         x_unpad, cu_seqlens, max_seqlen=8190,
         softmax_scale=1/√128=0.0884
       ) → output_unpad [nnz, 12, 128]
    ⑥ pad_input(output_unpad, indices, 4, 8190)
         → [4, 8190, 12, 128]

  【NPU 路径，无 FA】:
    q.transpose(1,2): [4, 12, 8190, 128]
    k.transpose(1,2): [4, 12, 8190, 128]
    v.transpose(1,2): [4, 12, 8190, 128]
    F.scaled_dot_product_attention(q,k,v):
      ① QK^T: BatchMatMul [4,12,8190,128] × [4,12,128,8190] → [4,12,8190,8190]
      ② Scale: * (1/√128)
      ③ Softmax: [4,12,8190,8190]
      ④ @V: BatchMatMul [4,12,8190,8190] × [4,12,8190,128] → [4,12,8190,128]
    out.transpose(1,2): [4, 8190, 12, 128]

attn 输出: [4, 8190, 12, 128]

─── 输出投影 ─────────────────────────────────────────────────────────────────
flatten(2): [4, 8190, 1536]
Linear_o: MatMul → [4, 8190, 1536]
```

### 3.3 Cross-Attention（text→image）

```
x（image query）: [4, 8190, 1536]
text:             [4, 512,  1536]  （已经 Repeat×4）

q = RMSNorm(Linear_q(x))   [4, 8190, 12, 128]
k = RMSNorm(Linear_k(text)) [4, 512,  12, 128]
v = Linear_v(text)          [4, 512,  12, 128]

注意：cross-attn 无 RoPE，无 register token 处理

flash_attn_no_pad(q, k, v, attn_mask=img_mask, attn_mask_kv=None, is_cross_attn=True):
  因 kv 无 mask（is_cross_attn=True, no_mask_kv=True），走直通路径:
  flash_attn_func(q, k, v, ...) 或 scaled_dot_product_attention
  q: [4, 8190, 12, 128]  vs  k/v: [4, 512, 12, 128]  → 非对称 seq len

输出: [4, 8190, 12, 128]
flatten + Linear_o → [4, 8190, 1536]
```

### 3.4 Single→Group 过渡（skiparse_2d_single_to_group）

发生在 Single Block 结束、Group Block 开始之间的 `rearrange_input`：

```
输入 x: [4, 8190, 1536]   （Single 模式：每份是间隔采样的 token）

skiparse_2d_single_to_group:
  '(p2 q2 b) (txh_p1 p1 w_q1 q1) c -> (p1 q1 b) (txh_p1 p2 w_q1 q2) c'
  p1=q1=p2=q2=2, w_q1 = W//4 = 13

  ① Reshape: [4, 8190, 1536]
            → [2, 2, 1, 21, 2, 15, 2, 1536]  ← 展开所有维度（txh=21, p1=2, w_q1=13, q1=2 → 实际 txh_p1=21, p1=2, w_q1=13, q1=2)
            注：8190 = 21 * 2 * 13 * 2 * ... 参见代码
  ② Permute: 调整维度顺序，将 (p2,q2) → batch，(p1,q1) → seq 内
  ③ contiguous() → 实际内存重排
  ④ Reshape → [4, 8190, 1536]

  语义效果：
    Single 模式 = 每个子批次持有 2D 空间上间隔为 2 的稀疏采样集合
    Group  模式 = 每个子批次持有局部 2×2 邻域的 token 集合
    → Single 让每个 token 能看到全局稀疏背景
    → Group  让每个 token 能看到局部邻域细节
    → 两者配对 = 既有全局感受野又有局部感受野
```

### 3.5 Group Block 结束：还原为全局 x（is_skiparse2full_block=True）

```
rearrange_output: skiparse_2d_group_reverse
  '(p1 q1 b) (txh p2 w q2) c -> b (txh p1 p2 w q1 q2) c'
  [4, 8190, 1536] → [1, 32760, 1536]

register_rearrange_output: Reduce（mean over P²=4 维度）
  [4, Nr, 1536] → [1, Nr, 1536]

至此 x 恢复原始全局 shape [1, 32760, 1536]，进入下一个 Full Block
```

## 四、反向传播关键点

### 4.1 skiparse rearrange 的梯度

`skiparse_func.py` 中的并行版（`ParallelSkiparse2DSingle2Group`）是自定义 `torch.autograd.Function`：

```python
# 前向: single → group
forward:  _parallel_skiparse_2d_single_to_group(x, ...)

# 反向: group → single（互逆变换）
backward: grad_input = _parallel_skiparse_2d_group_to_single(grad_output, ...)
```

非并行版（普通 rearrange）因为都是 reshape+permute，PyTorch 自动计算梯度（`permute` 的梯度是反向 permute，`reshape` 的梯度是反向 reshape）。

### 4.2 FlashAttention 反向

```
FA2/FA3 内核保存 softmax log-sum-exp (lse) 用于梯度计算
不保存完整 attention score（节省显存）

反向输入: dOutput [4, 8190, 12, 128]
反向输出:
  dQ [4, 8190, 12, 128]  ← 来自 softmax 梯度 + V 转置乘
  dK [4, 8190, 12, 128]  ← 来自 Q 转置乘
  dV [4, 8190, 12, 128]  ← 直接来自 attn_score 转置乘
```

### 4.3 梯度检查点（gradient_checkpointing）

`block_forward` 被 `torch.utils.checkpoint.checkpoint` 包裹时：
- **前向**：不保存中间激活（norm/attn/ffn 的输出）
- **反向**：重新执行一次前向以重建激活，再计算梯度
- 代价：前向多算一遍（约 +33% 计算量），换取显存节省
