# TorchDiff 项目架构分析

> 分析日期：2026-03-18

---

## 一、项目血缘

```
Wan2.1 (阿里巴巴, 开源)
    └── TorchDiff (本项目, Open-Sora-Plan 的延续)
            ├── WanModel (完整复用 Wan2.1 架构，全注意力)
            └── OSPNextModel (核心创新：Skiparse 稀疏注意力)
```

- **权重来源**：直接加载 `Wan2.1-T2V-1.3B` 或 `Wan2.1-T2V-14B` 的权重作为预训练起点
- **与 Open-Sora-Plan 关系**：是其 OSP-Next 分支，重点做推理加速（稀疏注意力），而不是增加新功能
- **代码依赖**：`want2v.py` 中的 `WanLayerNorm / WanRMSNorm / Head / sinusoidal_embedding_1d` 直接被 `osp_next.py` import 复用

## 二、完整模型框架（1.3B T2V 为例）

```
输入视频帧 (B, C, T, H, W)
        │
        ▼
   WanVAE.encode()          ← vae.py  (Wan2.1 的 3D VAE, fp32, 不训练)
        │  压缩到 latent space，spatial 8x down, temporal 4x down
        ▼
   latent (B, 16, T', H', W')    T'=T/4, H'=H/8, W'=W/8
        │
        │        T5EncoderModel(prompt_ids)   ← t5.py (UMT5-XXL, bf16, 可选 FSDP)
        │             │ text_embeddings (B, 512, 4096)
        │             │
        ▼             ▼
   OSPNextModel.forward(latents, timesteps, text_embeddings)
        │
        ├─ patch_embedding (Conv3d, stride=(1,2,2))  → (B, T'*H''*W'', dim)
        ├─ time_embedding (sinusoidal → MLP)         → e0 (B, 6, dim)
        ├─ text_embedding (Linear → GELU → Linear)   → text (B, 512, dim)
        ├─ [30 个 OSPNextAttentionBlock]
        └─ head → unpatchify → output (B, 16, T', H', W')
        │
        ▼
   scheduler.training_losses(output, target, prior_dist)   ← flow_matching.py
        │
        ▼
   loss.backward()
```

## 三、问题1：NPU 多卡训练完整调用链

### 启动入口
```
scripts/train/npu/train_osp_1_3b.sh
    └── 设置 HCCL/Ascend 环境变量
    └── torchrun --nproc_per_node=8 \
                 train/train_osp.py \
                 --config configs/train/npu/osp_1_3b.yaml
```

### 逐层调用链

```
train/train_osp.py
  line 9:  from torchdiff.utils.utils import check_and_import_npu
  line 11: check_and_import_npu()           ← utils/utils.py
               if is_npu_available():
                   import torch_npu
                   transfer_to_npu()        ← 所有 cuda 算子自动重定向到 NPU
                                               "cuda:x" → "npu:x"

  main(config):
    setup_distributed_env()                 ← distributed/utils.py
    init_device_mesh("cuda", (ddp,fsdp))    ← PyTorch DDP+FSDP2

    WanVAE(vae_pth, dtype="fp32")           ← modules/vae.py
    T5EncoderModel(checkpoint_path, ...)    ← modules/t5.py

    models["osp_next"](**model_config)      ← modules/__init__.py
       → osp_next.models["osp_next"]        ← modules/osp_next.py
           → OSPNextModel.__init__()
               └── OSPNextAttentionBlock × 30
                       └── OSPNextSelfAttention
                               └── attention_with_mask()  ← modules/attention.py
                                   # NPU: 用 torch 原生 scaled_dot_product_attention
                                   # GPU: 用 flash_attn 库

    FSDP2_mix_wrapper(model, dp_mesh, ...)  ← distributed/fsdp2_wrapper.py

    EMAModel(model, decay=0.9993)           ← distributed/fsdp_ema.py

    训练循环 while current_iteration < training_iteration:
        video, prompt_ids → vae.encode() + text_encoder()
        encoder_cache_manager(...)          ← utils/encoder_cache.py
        scheduler.q_sample(latents)         ← schedulers/flow_matching.py
        model(interpolated_latents, t, text)
        scheduler.training_losses(output, latents)
        loss.backward()
        adaptive_grad_clipper.adaptive_clip()  ← utils/clip_grads.py
        optimizer.step()
        ema_model.update()
        checkpointer.save(...)              ← distributed/checkpoint.py
```

### NPU vs GPU 关键区别
| 项目 | GPU | NPU |
|------|-----|-----|
| Attention 实现 | `flash_attention` (flash_attn 库) | `attention` (torch 原生 sdpa) |
| RoPE 实现（want2v.py） | `torch.polar` 复数 | NPU 上转 `complex64` 再算 |
| RoPE 实现（osp_next.py） | 实数 cos/sin | 实数 cos/sin（专门为 NPU 重写） |
| 设备重定向 | 无需 | `transfer_to_npu()` 全局重定向 |
| Profiling | `torch.profiler` | `torch_npu.profiler` |
| 通信库 | NCCL | HCCL（`HCCL_CONNECT_TIMEOUT` 等变量） |

## 四、问题2：OSPNextModel 详细分析 及与 WanModel 的对比

### 共同框架（两者都是 DiT 结构）

- 3D patch embedding (Conv3d, stride 1×2×2)
- 3D RoPE（时间/高/宽三维旋转位置编码）
- 每个 block：`Self-Attn → Cross-Attn（T5文本）→ FFN`，用 AdaLN-like modulation（6个scale/shift参数）调制

### 核心差异表

| 特性 | WanModel (want2v.py) | OSPNextModel (osp_next.py) |
|------|---------------------|---------------------------|
| **Self-Attention** | 全序列注意力 O(N²) | Skiparse 稀疏 ~O(N²/P²) |
| **Block 类型** | 单一 WanAttentionBlock | Full / Single / Group 三态 |
| **注意力入口** | `flash_attention` or `attention` | `attention_with_mask` (带稀疏mask) |
| **RoPE** | `torch.polar` 复数 | 实数 cos/sin，NPU 友好 |
| **Context Parallel** | Ulysses CP（seq 维度切） | Ulysses CP + Skiparse CP（二维空间切） |
| **Register Tokens** | 无 | 可选（skiparse block 间信息传递） |
| **模型尺寸(1.3B)** | dim=2048, 32层, 16头 | dim=1536, 30层, 12头 |
| **模型尺寸(14B)** | dim=5120, 40层, 40头 | dim=5120, 40层, 40头 |

### Skiparse 核心思想

全序列 `N = T × H × W` 个 tokens，sparse_ratio=P：

```
Skiparse 2D (本项目默认，sparse_ratio=2 即 P=2):

原始空间 H×W (例 60×104):
  Single block: 每 2×2 格子采样位置 (0,0)  → 1/4 密度
  Group  block: 每 2×2 格子采样位置 (1,0)(0,1)(1,1) → 合并3个子组

两种 block 交替出现 → 合并后覆盖全序列
时间维度 T 不做稀疏化（只做 full 注意力）
```

### Block 布局（Uniform 模式，1.3B 配置）

```yaml
num_layers: 30, num_full_blocks: 10, sparse_ratio: 2, skiparse_2d: True
```

```
full_block_interval = 30 / (10/2) = 6
每 6 个 block 的前 2 个是 Full block：

Block  0,1  → Full, Full
Block  2,3  → Single, Group
Block  4,5  → Single, Group
Block  6,7  → Full, Full
Block  8,9  → Single, Group
Block 10,11 → Single, Group
Block 12,13 → Full, Full
...
```

### OSPNextModel.forward() 主要步骤

```python
x = patch_embedding(x)              # Conv3d patchify
e = time_embedding(sinusoidal(t))    # 时间条件
e0 = time_projection(e)              # (B, 6, dim) → 6个 scale/shift

x, grid_sizes = patchify(x)          # (B, T*H*W, dim)

# Context Parallel 预处理：按空间2D切分给各卡
x, sub_grid_sizes = context_preprocessor.preprocess(x, grid_sizes)

# 生成 Skiparse 稀疏 attention mask
local_single_mask, local_group_mask, ... = mask_preprocessor.preprocess(...)

for block in blocks:
    # Full block: mask=None，全注意力
    # Single block: 用 global_single_mask，只看 single 子集
    # Group  block: 用 global_group_mask，只看 group 子集
    x, register_tokens = block(x, attn_mask, cross_attn_mask, e0, ...)

x = head(x, e)                        # 最终输出层
x = context_preprocessor.postprocess(x, ...)  # 各卡结果拼回
x = unpatchify(x)                     # 还原 (B, 16, T', H', W')
```

## 五、问题3：框架改动集中在哪里

### 主要文件

| 文件 | 角色 | 改动程度 |
|------|------|----------|
| `torchdiff/modules/osp_next.py` | **核心模型** | 全新，~1600行 |
| `torchdiff/modules/skiparse_func.py` | Skiparse 元函数 | 全新 |
| `torchdiff/modules/attention.py` | attention 入口 | 增加 `attention_with_mask` |
| `torchdiff/modules/want2v.py` | Wan 原始模型 | 基本不变，被 osp_next.py import |
| `torchdiff/distributed/cp_state.py` | CP 状态管理 | 新增 skiparse_cp 相关字段 |
| `torchdiff/distributed/communication.py` | 分布式通信 | 新增 all_to_all 系列 |
| `train/train_osp.py` | 训练主程序 | 相比 train.py 增加 skiparse CP 逻辑 |
| `configs/train/npu/osp_1_3b.yaml` | 配置文件 | skiparse 相关参数 |

### osp_next.py 内部层次

```
osp_next.py
├── rope_params()                   实数 RoPE（NPU 兼容）
├── ContextParallelType             CP 类型枚举（CP/SkiparseCP/FullBlocksCP/GlobalCP）
├── SkiparseModelType               Full / Uniform / DualEnd
├── SkiparseBlockType               Full / Single / Group
├── RearrangeType                   所有重排类型枚举
├── SkiparseRearrange               带 padding 的 skiparse 重排 nn.Module
├── MetaPreprocessor                抽象基类
├── ContextParallelPreprocessor     CP 下的序列预处理/后处理（2D空间切分）
├── SkiparseMaskPreprocessor        生成 block attention mask
├── SkiparseRopeWrapper             实数 RoPE 应用（缓存 cos/sin）
├── OSPNextSelfAttention            稀疏自注意力（含 all2all CP）
├── OSPNextCrossAttention           交叉注意力（文本 cross-attn）
├── OSPNextAttentionBlock           单个 block（三态：Full/Single/Group）
└── OSPNextModel                    完整模型（顶层）
```

## 六、续训时需要修改的地方

### 场景A：最简单续训（只改 config）

```yaml
# configs/train/npu/osp_1_3b.yaml

model_config:
  # 指定续训起点（目录或 .safetensors 文件）
  pretrained_model_dir_or_checkpoint: "/path/to/checkpoint_dir_or_file"

data_config:
  dataset_config:
    metafile_or_dir_path: "/path/to/your_data.lmdb"

output_dir: "output/your_exp_name"   # checkpointer 会自动找最新 checkpoint 续接

optimizer_config:
  lr: 0.000005   # 续训通常用更小的 lr（原来 2e-5，续训可用 5e-6）
```

> **注意**：只要 `output_dir` 里有 checkpoint 文件，`train_osp.py` 的 checkpointer 会**自动续训**（包括模型权重、优化器状态、数据 sampler 状态、随机状态）。

### 场景B：冻结主干，只训练新增参数（register tokens）

```yaml
model_config:
  lock_main_parameters: True   # 冻结除 register_tokens 外所有参数
  num_register_tokens: 1024    # 需要 > 0
```

### 场景C：从 Full-Attn 蒸馏到 Skiparse（训练初期使用）

```yaml
model_config:
  training_with_full: True
  skiparse_model_type: "uniform"
  pretrained_model_dir_or_checkpoint: "/path/to/sparse_init"
  pretrained_full_model_dir_or_checkpoint: "/path/to/full_wan_weights"
# 此时 loss = MSE(sparse_output, full_output)，而不是 flow matching loss
```

### checkpointer 自动续训逻辑（train_osp.py:284）

```python
if checkpointer.last_training_iteration is not None:
    checkpointer.load_model(model)
    checkpointer.load_model(model, ema=True)
    checkpointer.load_optim(model, optimizer)
    checkpointer.load_dataloader_state_dict(dataloader)
    checkpointer.load_rng_state_dict()
```
