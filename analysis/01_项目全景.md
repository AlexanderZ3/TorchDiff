# TorchDiff 项目全景

> 初稿：2026-03-18

---

## 血缘关系

```
Wan2.1 (阿里巴巴, 开源)
    └── TorchDiff (本项目)
            ├── WanModel     — 复用 Wan2.1 原始架构（全注意力）
            └── OSPNextModel — 核心创新：Skiparse 稀疏注意力
                               Open-Sora-Plan OSP-Next 分支
```

- 权重：直接从 `Wan2.1-T2V-1.3B` / `Wan2.1-T2V-14B` 加载做 fine-tune
- 目标：在 Wan2.1 基础上引入稀疏注意力，降低长视频训练显存/计算量
- 同时支持 GPU（flash_attn）和 NPU（torch_npu），代码共用一套

## 两种模型对比（一句话）

| 模型 | 文件 | 注意力 | 适用场景 |
|------|------|--------|----------|
| WanModel | `want2v.py` | 全注意力 O(N²) | 对齐 Wan2.1 原版，质量基线 |
| OSPNextModel | `osp_next.py` | Skiparse 稀疏 ~O(N²/P²) | 长视频、低显存训练 |

## 训练启动（快速参考）

```bash
# NPU 单节点 OSPNext 1.3B
bash scripts/train/npu/train_osp_1_3b.sh

# NPU 多节点 OSPNext 1.3B
bash scripts/train/npu/train_osp_1_3b_multinode.sh

# GPU 单节点 Wan 14B
bash scripts/train/gpu/train_t2v_14b.sh
```

## 续训最小改动

编辑 `configs/train/npu/osp_1_3b.yaml`：
```yaml
model_config:
  pretrained_model_dir_or_checkpoint: "/path/to/checkpoint"
data_config:
  dataset_config:
    metafile_or_dir_path: "/path/to/data.lmdb"
output_dir: "output/your_exp"
optimizer_config:
  lr: 0.000005  # 续训用更小 lr
```
`output_dir` 里有 checkpoint 时自动续接（模型+优化器+数据进度+随机状态）。
