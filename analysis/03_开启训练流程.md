## 二、Dummy 数据集原理（无需准备任何视频）

代码中 `torchdiff/data/datasets/t2v_dataset.py` 已内置 **`T2VRandomDataset`**：

```python
class T2VRandomDataset(BaseDataset):
    def __len__(self):
        return 1000000  # 虚拟100万条样本

    def getitem(self, index):
        examples[VIDEO] = torch.randn(3, self.sample_num_frames,
                                       self.sample_height, self.sample_width)
        # 文本用空字符串，走tokenizer编码
        examples[PROMPT_IDS], examples[PROMPT_MASK] = self.get_text_data("")
        return examples
```

**只需在 yaml 里写 `dataset_name: "t2v_random"`**，完全跳过 LMDB 文件读取，生成随机张量直接送 VAE 编码。

## 四、创建启动脚本

创建文件：`scripts/train/npu/train_osp_1_3b_dummy.sh`

```bash
#!/bin/bash

# === NPU 环境变量 ===
export TOKENIZERS_PARALLELISM=false
export CUDA_DEVICE_MAX_CONNECTIONS=1
export ASCEND_SLOG_PRINT_TO_STDOUT=0
export ASCEND_GLOBAL_LOG_LEVEL=3
export MULTI_STREAM_MEMORY_REUSE=1
export PYTORCH_NPU_ALLOC_CONF=expandable_segments:True
export TASK_QUEUE_ENABLE=1
export COMBINED_ENABLE=1
export CPU_AFFINITY_CONF=1
export HCCL_CONNECT_TIMEOUT=3600
export HCCL_EXEC_TIMEOUT=0
export ACL_DEVICE_SYNC_TIMEOUT=3600

# === 关闭 wandb 联网 ===
export WANDB_MODE=offline

# === 分布式参数（单节点8卡）===
MASTER_ADDR=${MASTER_ADDR:-127.0.0.1}
MASTER_PORT=${MASTER_PORT:-29505}
NPRC_PER_NODE=${NPRC_PER_NODE:-8}   # 改成实际NPU卡数，如4或1

torchrun \
  --nproc_per_node=${NPRC_PER_NODE} \
  --nnodes=1 \
  --master_addr=${MASTER_ADDR} \
  --master_port=${MASTER_PORT} \
  train/train_osp.py \
  --config configs/train/npu/osp_1_3b_dummy_8npu.yaml
```

## 六、关键参数约束（避免踩坑）

| 参数 | 规则 | 示例（8卡）|
|------|------|-----------|
| `fsdp_size` | ≤ world_size，且 world_size % fsdp_size == 0 | 8 |
| `skiparse_cp_size` | sparse_ratio=2,skiparse_2d=True时: cp_size ∈ {1,2,4} | 2 |
| `world_size` | = dp × skiparse_cp × cp | 4×2×1=8 |
| 关闭CP时 | `use_skiparse_context_parallel: False`，`skiparse_cp_size`填1 | — |

代码中的自动保护（`train_osp.py` L124-126）：
```python
if fsdp_size > world_size:
    fsdp_size = world_size  # 自动降级，不会报错
```

## 七、权重加载逻辑说明

训练脚本 `train_osp.py` L220-298 的加载优先级：

```
1. output_dir 有 checkpoint → 断点续训（最高优先级）
2. pretrained_model_dir_or_checkpoint 是目录 → from_pretrained()
3. pretrained_model_dir_or_checkpoint 是 .safetensors 文件 → 直接 load（当前情况）
4. 都没有 → 随机初始化
```

当前场景走第3条路径，从 `.safetensors` 文件加载 Wan2.1 预训练权重作为起点。

## 九、后续续训真实数据的改动

跑通 dummy 后，切换真实数据只需改 yaml 的 `data_config` 部分：

```yaml
data_config:
  dataset_name: "wan_t2v"    # 改回真实数据集
  dataset_config:
    metafile_or_dir_path: "/path/to/your.lmdb"  # 添加LMDB路径
    text_tokenizer_path: "/path/to/google/umt5-xxl"
    ...
  num_workers: 16            # 真实数据可以开多worker
```

同时将 `output_dir` 指向上次 dummy 训练的 checkpoint 目录，即可从已保存的权重继续。

## 补充：
### 问题1：复现 OSP-Next 训练，单机8卡 NPU
完整调用链：

bash scripts/train/npu/train_osp_1_3b.sh
  └── torchrun --nproc_per_node=8
        └── train/train_osp.py  --config configs/train/npu/osp_1_3b.yaml
              ├── 加载 Wan2.1 1.3B .safetensors 权重
              ├── 初始化 OSPNextModel（skiparse架构）
              ├── FSDP2 包装 + EMA
              └── flow matching loss 训练
                    └── torchdiff/modules/osp_next.py → OSPNextModel
核心要点：OSPNextModel 直接从 Wan2.1 权重初始化，无需任何权重转换。

原因：OSPNextModel 的所有 block（自注意力/交叉注意力/FFN/归一化层）参数名和维度与 WanModel 完全对应，代码在 train_osp.py L293-295 直接用 checkpointer.load_model_from_path() 加载 .safetensors，key 可以直接匹配。

你需要改的只有两处：

configs/train/npu/osp_1_3b.yaml：


# 1. 改三个路径
pretrained_model_dir_or_checkpoint: "/你的路径/diffusion_pytorch_model.safetensors"
vae_path: "/你的路径/Wan2.1_VAE.pth"
checkpoint_path: "/你的路径/models_t5_umt5-xxl-enc-bf16.pth"
text_tokenizer_path: "/你的路径/google/umt5-xxl"

# 2. 改数据路径（或用 dummy）
metafile_or_dir_path: "/你的数据/xxx.lmdb"
scripts/train/npu/train_osp_1_3b.sh：


# 删掉 wandb 登录那几行（或改成 offline）
export WANDB_MODE=offline
# 删掉 WANDB_API_KEY 行（别把别人的key留在脚本里）
其余不需要改，官方配置 training_with_full: False, lock_main_parameters: False 就是标准的从Wan权重复现OSP-Next的设置。
